# Linux System Monitor

## About the Project
Linux System Monitor is a beginner-friendly Python project that displays important system information using Linux system files and Python libraries.

## Features
- Displays computer name and operating system details.
- Reads total and available memory.
- Calculates RAM usage in MB and percentage.
- Displays CPU model and number of CPU cores.
- Shows total, used, and free disk space.
- Displays the current date and time.

## Technologies Used
- Python 3
- Ubuntu Linux
- WSL2
- Visual Studio Code

## How to Run

1. Open Ubuntu terminal.
2. Navigate to the project directory:

```bash
cd ~/Linux-System-Monitor
```

3. Run the program:

```bash
python3 monitor.py
```

## Learning Outcomes
- Understanding Linux system information.
- Reading files from the `/proc` filesystem.
- Using Python's `platform`, `os`, and `datetime` modules.
- Calculating RAM and disk usage.
